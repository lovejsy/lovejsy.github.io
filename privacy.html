개인정보처리방침

ktcloud_manager · 시행일 2026년 9월 12일

ktcloud_manager(이하 "본 앱")는 이용자의 개인정보를 중요하게 생각합니다. 본 방침은 본 앱이 어떤 정보를 다루고, 무엇을 수집하지 않는지를 설명합니다.

1. 개발자가 수집하지 않는 정보

본 앱의 개발자는 이용자로부터 어떠한 개인정보도 수집하거나 보관하지 않습니다.

이용자가 입력한 kt cloud API 키, 시크릿, 비밀번호, 인증 토큰은 기기 내부 저장소에만 저장되며 개발자에게 전송되지 않습니다. 모든 API 요청은 이용자 본인의 kt cloud 계정으로 직접 전달되고, 그 응답 또한 기기에서만 처리됩니다. 앱을 삭제하면 저장된 정보도 함께 삭제됩니다.

2. 광고를 통해 수집되는 정보

본 앱은 무료로 제공되며 Google AdMob을 통해 배너 광고를 게재합니다. 광고 제공을 위해 Google이 아래 정보를 수집할 수 있습니다.

구분항목이용 목적
식별자기기 ID(광고 식별자)광고 게재, 빈도 제한, 분석
사용 데이터광고 데이터, 제품 상호작용광고 성과 측정
위치대략적인 위치지역 기반 광고 (IP 기반 추정)
진단충돌·성능·기타 진단 데이터서비스 품질 개선

본 앱은 위치 권한을 요청하지 않습니다. 대략적인 위치는 Google이 IP 주소로 추정하는 수준의 정보입니다. 수집 항목의 최신 기준은 Google의 데이터 공개 문서를 따릅니다.

3. 추적 및 이용자 선택권

본 앱은 iOS의 앱 추적 투명성(App Tracking Transparency)에 따라 맞춤형 광고를 위한 추적 동의를 요청합니다. 동의는 전적으로 선택 사항이며, 거부하셔도 앱의 모든 기능을 동일하게 이용하실 수 있습니다. 거부 시에는 맞춤형이 아닌 일반 광고가 표시됩니다.

동의 여부는 언제든지 iOS 설정 → 개인정보 보호 및 보안 → 추적에서 변경하실 수 있습니다.

4. 제3자 제공

개발자는 이용자의 정보를 제3자에게 판매하거나 제공하지 않습니다. 광고 관련 정보는 Google의 개인정보처리방침에 따라 처리됩니다. 자세한 내용은 Google 개인정보처리방침과 Google의 파트너 사이트 정보 이용 방식을 참고해 주세요.

5. 아동의 개인정보

본 앱은 클라우드 인프라 관리 도구로서 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

6. 방침의 변경

본 방침이 변경되는 경우 이 페이지에 변경된 내용과 시행일을 게시합니다.
