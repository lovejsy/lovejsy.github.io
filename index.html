ktcloud_manager

iOS에서 kt cloud 자원을 조회하고 관리하는 비공식 클라이언트 앱입니다.

주요 기능

  • 가상 서버(VM) 목록 조회 · 생성 · 시작/정지 · 삭제
  • 서버 이미지 및 스냅샷 관리
  • 디스크 볼륨 관리
  • 방화벽 · 포트포워딩 정책 조회 및 등록
  • 트래픽 사용량과 자원 사용 추이 분석
  • G1 · G2 · D1 등 다중 존(zone) 지원

계정 정보에 관하여

본 앱은 사용자가 입력한 kt cloud API 자격증명을 기기 내부에만 저장하며, 개발자에게 전송하거나 수집하지 않습니다. 모든 API 요청은 사용자 본인의 kt cloud 계정으로 직접 전달됩니다.
